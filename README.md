# Snail

A fun and engaging game project developed as an academic assignment at Francisco Gavidia University.

## 🎮 Features

- **Object-Oriented Architecture:** Built using modular Python classes to efficiently manage game entities and behaviors.
- **Dynamic Level Management:** Custom functions that handle level progression and instantiate objects on the fly.
- **State-Driven Main Loop:** A robust while loop that controls the core game states, including the main menu and level transitions.
- **Retry & Exit Mechanism:** Features smart conditionals for game-over and victory states, allowing the player to seamlessly restart the loop or exit the GUI.

## 📋 Requirements

- **Python 3.6 to 3.13** (Recommended version range)
- **Pygame library** (installed via `pip install pygame`)
